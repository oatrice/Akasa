### Manual Verification Guide

Follow these steps to physically test the changes locally:

- **Step 1:** Update local dependencies.
  - Open your terminal and activate your virtual environment.
  - Run `pip install -r requirements.txt` to install the new `google-genai` package and remove `google-generativeai`.

- **Step 2:** Run the automated tests.
  - Run `pytest` to ensure all tests pass (specifically `tests/services/test_llm_service.py`).
  - **Expected Result:** All tests should pass without `google-generativeai` warnings.

- **Step 3:** Test the LLM integration locally.
  - Ensure you have your `.env` configured with a valid `GEMINI_API_KEY`.
  - Start the backend server: `uvicorn app.main:app --reload`
  - Trigger an action that calls the Gemini model. For example, send a message to your Telegram bot that requires an AI response (using a model identifier that triggers the Google SDK route).
  - **Expected Result:** The bot should respond correctly, confirming that `client.aio.models.generate_content` is functioning successfully with the new SDK.

- **Step 4:** Verify Python Environment (Optional).
  - If using Render CLI or a local Docker build imitating Render, ensure the build picks up Python `3.11.9` from the updated `render.yaml`.
